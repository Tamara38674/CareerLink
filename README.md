## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `careermatch-ai`.
2. Upload the **contents** of this folder to the repository root (not the ZIP).
3. Open Settings > Pages > Build and deployment > Deploy from a branch. Choose `main` and `/ (root)`, then Save.
4. Wait for the GitHub Pages link to appear and open it in an incognito browser. Check the video, navigation, quiz, and chatbot on both pages.
5. Submit that live URL in Canvas.

## Rubric notes
- Homepage video: five-second MP4, muted autoplay and loop.
- Two pages: `index.html` and `about.html`.
- X-factor: interactive career quiz (description at bottom of homepage).
- Chatbot: **rule-based scripted chat widget** on both pages. It responds to predefined questions, not a generative AI model. If your instructor requires an actual AI chatbot, replace it with a deployed Dify embed on both pages before submission.
